# PBRU Activity Discord Bot

บอท Discord แจ้งเตือนข่าวและกิจกรรมนักศึกษา **มหาวิทยาลัยราชภัฏเพชรบุรี (PBRU)** พร้อมรูปตรามหาวิทยาลัย

## แหล่งข้อมูลที่ติดตาม
- ข่าวประชาสัมพันธ์กิจกรรม: `https://sdd.pbru.ac.th/activity/new/news.php`
- กิจกรรมใกล้เข้ามาแล้ว: `https://sdd.pbru.ac.th/activity/new/`
- ปฏิทินกิจกรรมนักศึกษา PBRU (Google Calendar iCal สาธารณะ 2 ปฏิทิน)

> **หมายเหตุเรื่องระบบนักศึกษา (`student_dashboard.php`):** หน้าดังกล่าวต้องล็อกอินด้วยรหัสนักศึกษา บอทนี้จึงดึงข้อมูลจากหน้าข่าวและปฏิทินสาธารณะของกองพัฒนานักศึกษาโดยไม่ต้องเก็บรหัสผ่านนักศึกษา และหากประกาศไม่ได้ระบุหน่วยกิต/เงื่อนไขคณะไว้ในข้อความสาธารณะ บอทจะแสดงคำแนะนำพร้อมลิงก์ให้กดตรวจสิทธิ์ในระบบนักศึกษา PBRU

## รายละเอียดที่บอทแจ้งเตือน
- 📍 **ลงทะเบียนได้ที่ไหน** (ดึงลิงก์ `reg.pbru.ac.th`, แบบฟอร์ม หรือช่อง/ห้องรับสมัคร)
- 🗓️ **เริ่ม–สิ้นสุดการลงทะเบียน**
- 🎓 **เครดิต / ชั่วโมงจิตอาสา / คะแนนความประพฤติ**
- 🏫 **ลงได้ทุกคณะไหม**
- ⏰ **วัน-เวลา และสถานที่จัดกิจกรรม** + รูปโปสเตอร์กิจกรรม

## วิธีรัน 2 โหมด

### 1) โหมดแจ้งเตือนอัตโนมัติบน GitHub Actions (แนะนำ — ปลอดภัยตาม ToS ของ GitHub)
ไฟล์ `.github/workflows/check-activities.yml` จะทำงานอัตโนมัติทุก 15 นาที (`schedule: cron`) โดยเช็กเว็บ PBRU แล้วยิงแจ้งเตือนเข้า Discord แล้วจบงานในไม่กี่วินาที (ไม่รันลูป 6 ชม. ค้างไว้บน GitHub Actions ซึ่งเสี่ยงผิด ToS และถูกปิด repo)

ตั้งค่า Secrets ใน GitHub Repository (**Settings -> Secrets and variables -> Actions**):
- `DISCORD_BOT_TOKEN`
- `DISCORD_CHANNEL_ID`

### 2) โหมดบอทออนไลน์ 24 ชม. แบบ Real-time + Slash Commands (`/activities`, `/check`, `/status`)
สำหรับรันบนเครื่องตัวเอง, VPS, Docker, Railway หรือ Render เพื่อให้บอทแสดงสถานะ **Online 🟢** ตลอดเวลาและเช็กทุก 120 วินาที:

```bash
npm install
cp .env.example .env   # ใส่ DISCORD_BOT_TOKEN และ DISCORD_CHANNEL_ID
npm start
```
